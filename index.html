About

I am a Ph.D. student in Computer Engineering at USC, working in the FPGA/Parallel Computing Lab, advised by Prof. Viktor K. Prasanna and Prof. Raj Kannan.

My research interests include machine learning for systems, graph machine learning, agentic and physical AI, subquadratic neural network architectures, and heterogeneous computing and hardware/software co-design.

Selected Projects

LoCoMAP

Long-context memory access prediction for graph analytics

LoCoMAP separates observation history from prediction horizon to study how graph topology shapes memory access prediction. The evaluation tests predictor reuse across regenerated graphs and shuffled node layouts.

HPEC 2026 publication

TabConv

Low-computation CNN inference through table lookups

TabConv approximates CNN operations with precomputed table lookups. Priority masking selects layers to keep as exact computations, balancing arithmetic cost and model accuracy.

Paper (PDF) · Code
